# csharp-mini-projects
A collection of mini desktop applications built with C# and Windows Forms, showcasing event-driven programming, UI design, and practical problem-solving through projects like Tic Tac Toe and a Simple Pizza Ordering System.


# Tic Tac Toe Game (C# WinForms)
A simple desktop Tic Tac Toe game built using Windows Forms in C#. It features a clean UI, turn-based gameplay, winner detection, and game restart functionality. The project demonstrates event-driven programming, basic game logic, and UI rendering using GDI+.

# Pizza Order System (C# WinForms)
A desktop pizza ordering application built using C# and Windows Forms. Users can customize pizza size, toppings, crust type, and dining option, with real-time price calculation and order summary updates.
